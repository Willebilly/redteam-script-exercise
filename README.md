# redteam-script-exercise
A .sh script that will change the time to 100 years in the future, logg system and user info and then create a new file that, when run, will revert the changes made and remove itself and the original .sh file


Before running this. It is recommended to run in it in a controlled environment and to, (if possible), save a snapshot of your virtual linux machine BEFORE running redteam.sh
